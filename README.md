# Noderra — Digital Agency Demo

A premium, animated, responsive digital-agency demo built with plain HTML, CSS and JavaScript. No framework, build step or package installation is required.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. For best results, use a local static server (for example VS Code Live Server).

## Before showing/selling to a client
- The supplied Noderra logo is included as a transparent PNG watermark in the hero and footer. The compact header mark remains CSS-built for legibility.
- Update `CONTACT_EMAIL` in `js/main.js` to the real enquiry email address.
- Replace the illustrative concept projects and copy with client-approved work/content. The three project cards are explicitly labelled as illustrative concepts.
- Connect the form to a real backend or form service if you need submissions stored online. In this demo it opens the visitor's email application.
- Add the client's actual business address, phone number, privacy policy and social links if applicable.

## Files
- `index.html` — page structure and SEO metadata
- `css/style.css` — responsive visual design, animations and layouts
- `js/main.js` — scroll reveals, counters, mobile menu and enquiry form

## Notes
Google Fonts are loaded online; system fallbacks are included. All other visual artwork is made with CSS and HTML, so there are no external image assets to manage.
